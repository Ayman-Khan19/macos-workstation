# macOS Workstation

A simple macOS bootstrap repository for Cloud & DevOps.

## Included Software

- Homebrew
- Git
- GitHub CLI
- Python
- Node.js (NVM)
- Visual Studio Code
- Google Chrome
- Docker Desktop
- AWS CLI
- Terraform
- kubectl
- jq
- tree
- wget

## Installation

```bash
chmod +x install.sh
./install.sh
```
